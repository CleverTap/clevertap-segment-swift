# CHANGE LOG

Version 2.0.0 (TBD)
===================================
* Adds support for iOS 27, tvOS 27 and Xcode 27.
* Raises the minimum deployment versions to iOS 15.0 and tvOS 15.0.
* Raises `swift-tools-version` to 5.9.
* Drops watchOS from the supported platforms. The CleverTap iOS SDK ships watchOS support in a separate `CleverTapWatchOS` product that this destination does not link.
* Supports [analytics-swift v1.10.4](https://github.com/segmentio/analytics-swift) and [CleverTap iOS SDK v7.9.1](https://github.com/CleverTap/clevertap-ios-sdk/blob/master/CHANGELOG.md#version-791-october-30-2026).

Version 1.0.0 (8 September, 2025)
===================================
* Supports [analytics-swift v1.8.0](https://github.com/segmentio/analytics-swift) and [CleverTap iOS SDK v7.3.2](https://github.com/CleverTap/clevertap-ios-sdk/blob/master/CHANGELOG.md#version-732-august-08-2025).
